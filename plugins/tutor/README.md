# tutor

`/tutor` is a Claude Code skill that teaches one goal at a time, in plain markdown files that open in any markdown app. Lessons are short: a picture, few words, and questions. Your answers are graded when you say `done`, and the rules you pass come back later as spaced review. Use it to learn or practice a topic over several sessions.

## Install

```
/plugin marketplace add kadeski/skills
/plugin install tutor@kadeski
```

## Usage

```
/tutor <topic> [source: path or url]
```
