## Questions

**Q1.** What does `len({3, 3, 4})` return?

Answer: 2, a set keeps each value once (sure)

> **Feedback:** Right: the second 3 is dropped, so the set is `{3, 4}` (notes 1).

**Q2.** What does `[1, 2] + [3]` give?

Answer: [1, 2, 3]

> **Feedback:** Right: `+` joins two lists end to end.
