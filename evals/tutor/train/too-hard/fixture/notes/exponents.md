# Exponents

1. A power counts copies: a^n means n copies of a multiplied together, so 2^3 = 2 x 2 x 2 = 8.
2. Multiplying powers of the same base adds the exponents: a^m x a^n = a^(m+n). The base stays the same.
3. A power of a power multiplies the exponents: (a^m)^n = a^(m x n), since it is n copies of a^m.
4. Each step down in the exponent divides by the base once more. So any nonzero number to the power 0 is 1.
5. A negative exponent means one over the positive power: a^(-n) = 1 / a^n. It is a small positive number, not a negative one.
