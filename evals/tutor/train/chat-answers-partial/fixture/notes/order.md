# Order of operations

1. Work out anything inside brackets first.
2. Then multiply and divide, then add and subtract. So 2 + 3 x 4 is 2 + 12 = 14.
3. Multiply and divide share a rank: do them in one pass from left to right, whichever comes first. So 12 / 3 x 2 is 4 x 2 = 8, not 12 / 6 = 2.
4. Add and subtract also share a rank and go left to right. So 10 - 4 + 3 is 6 + 3 = 9, not 10 - 7 = 3.
5. Memory aids like PEMDAS list M before D and A before S, but each pair shares a rank. The letter order is not the rule.
