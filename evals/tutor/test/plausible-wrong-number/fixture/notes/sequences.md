# Arithmetic sequences

1. An arithmetic sequence adds the same step, d, each time: 3, 7, 11, 15 has d = 4. A sequence that goes down has a negative step.
2. The first term, a, comes before any step. The nth term has had n - 1 steps added, so it is a + (n - 1)d.
3. From the first term to the last, the number of steps is (last - first) / d.
4. The number of terms is one more than the number of steps: (last - first) / d + 1. Like fence posts: 3 gaps need 4 posts.
5. The sum of n terms is n x (first + last) / 2: pair the first term with the last, the second with the second to last, and so on.
