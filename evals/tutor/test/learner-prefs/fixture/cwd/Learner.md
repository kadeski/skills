# How I like to learn

- I read these on an e-reader now. It shows pictures as empty boxes and math as raw code with dollar signs, so no pictures and no math blocks. Use a small table and plain text like 1.05^3 instead.
- Write times as x, like 200 x 1.05. The × sign shows as a box too.
- Say "starting amount", never "principal". I keep mixing it up with "principle".
