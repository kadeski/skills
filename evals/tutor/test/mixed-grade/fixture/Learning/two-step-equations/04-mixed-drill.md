# 04 Mixed drill

Part of [Solving Two-Step Equations](goal.md). Add `sure` or `guess` after any answer, and say `done` when finished.

Help is down to 2 after two first-try passes: a table to work from, no worked examples.

## Review

**R1.** x - 9 = 4. What is x?

Answer: -5, take 9 from both sides to get rid of the 9 (sure)

## The rules

| What was done to x | Undo it with |
|---|---|
| add a number | subtract it |
| subtract a number | add it |
| multiply by a number | divide by it |
| divide by a number | multiply by it |

With two steps, undo the last one first. Check by putting your answer back in.

## Questions

**Q1.** 3x + 5 = 20. What is x?

Answer: 5 (sure)

**Q2.** 5x + 13 = 48. What is x?

Answer: 5x = 48 - 13 = 25, so x = 5

**Q3.** 2x + 6 = 14. What is x?

Answer: divide by 2 first, so x + 6 = 7 and x = 1 (sure)

**Q4.** x / 3 - 2 = 5. What is x?

Answer: 7/3 (guess)

**Q5.** 4x + 2 = 16. What is x?

Answer: 4x = 14, so x = 14/4
