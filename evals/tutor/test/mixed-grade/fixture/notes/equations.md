# Solving equations

1. An equation is a balance: doing the same thing to both sides keeps it true.
2. Add and subtract undo each other, and so do multiply and divide.
3. To solve a one-step equation, do the inverse step to both sides. So x + 9 = 15 gives x = 15 - 9 = 6, and x / 4 = 5 gives x = 5 x 4 = 20.
4. In 3x + 5 = 20, x was multiplied by 3 and then 5 was added. Undo them in reverse order: subtract 5 from both sides (3x = 15), then divide both sides by 3 (x = 5).
5. Dividing first works only if you divide every term: 3x + 5 = 20 becomes x + 5/3 = 20/3. Dividing just the x term breaks the balance.
6. Check an answer by putting it back into the first equation: 3 x 5 + 5 = 20.
