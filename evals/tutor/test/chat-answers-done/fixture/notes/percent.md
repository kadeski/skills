# Percent

1. Percent means per hundred: 30% is 30/100, or 0.30.
2. To find p% of a number, multiply the number by p/100. So 30% of 50 is 0.30 x 50 = 15.
3. Percent change = (new - old) / old x 100. A positive result is an increase, a negative one a decrease.
4. The change is measured against where you started, so you divide by the old value.
5. To undo an increase of p%, divide by (1 + p/100). Taking p% off the new value does not get you back to the start.
