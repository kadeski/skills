# Adding fractions

1. A fraction a/b means a pieces, each 1/b of the whole.
2. Multiplying the top and the bottom by the same whole number gives an equal fraction: 1/3 = 2/6 = 4/12. Dividing both by a common factor simplifies it.
3. Tops can be added or subtracted only when the bottoms match: 2/7 + 3/7 = 5/7.
4. To add or subtract fractions with different bottoms, rewrite both over a common denominator first, then add or subtract the tops. Any common multiple of the bottoms works; the least one keeps the numbers small.
5. To add mixed numbers, add the whole parts and the fraction parts, then carry any whole that the fraction part makes.
