# Conditional probability from counts

1. A two-way table splits a group by two yes-or-no questions, so each person lands in exactly one cell, and the cells add up to the whole group.
2. P(A) from counts is the number with A divided by the whole group.
3. P(A given B) looks only at the people with B. It is the number with both A and B, divided by the number with B.
4. P(A given B) and P(B given A) share a top number, the count with both, but divide by different groups, so they are usually different.
5. A base rate is how common something is in the whole group, before you learn anything else about a person.
