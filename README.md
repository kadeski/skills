# skills

Claude Code plugins by Kaden Staker. Add this marketplace once, then install any plugin from it.

```
/plugin marketplace add kadeski/skills
/plugin install tutor@kadeski
```

## Plugins

- [tutor](plugins/tutor): teaches one goal at a time in plain markdown files. Short lessons are graded when you say `done`, and the rules you pass come back later as spaced review.
